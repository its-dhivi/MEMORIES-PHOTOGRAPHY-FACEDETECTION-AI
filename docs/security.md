# Security and privacy

Face embeddings are sensitive biometric data. They remain in PostgreSQL and are never returned by public or dashboard APIs.

Internal AI calls use a constant-time-checked service token and private networking. Images are signature-decoded, byte/pixel bounded, decompression-bomb protected, and never logged. Guest selfies remain in memory and are not stored by default.

Guest search requires an opaque HMAC-hashed short-lived session, active event access, optional Argon2 PIN, current explicit biometric consent, event isolation, compatible model version, threshold passage, and rate limits. Search/result access binds both guest session and event; knowing a search ID is insufficient. Withdrawal expires searches, while deleted photos are filtered from previous results.

Before production: deploy TLS/mTLS or workload identity internally, managed secrets, distributed limits, encrypted database/storage, retention cleanup, consent deletion operations, audit export, abuse monitoring, penetration testing, and qualified DPDP/child-safety review.

# Phase 4 guest controls

- Opaque guest credentials are HMAC-hashed in PostgreSQL and exposed to the browser only as Secure (production), HttpOnly, SameSite cookies.
- The BFF checks same-origin request metadata for mutations; NestJS independently enforces event scope, search ownership, consent, expiry, event status, and download settings.
- Consent withdrawal revokes the guest session, expires active searches and ZIP jobs, and removes browser search state. Already-issued presigned URLs may remain usable for at most two minutes.
- Original and ZIP keys never appear in API responses. Presigned URLs are short-lived; storage buckets remain private.
- PIN attempts, biometric searches, downloads, and ZIP creation have endpoint-specific rate limits. Raw selfies, embeddings, tokens, and full presigned URLs must not be logged.
- ZIP exports are limited by configured count and estimated original bytes, generated by a single-concurrency streaming worker, and deleted after expiry.
- Production event approval requires a trusted HMAC-signed evaluation artifact with event/model/version binding and gallery-level sample, precision, recall, and false-acceptance criteria. The signing secret is server-only and is not passed to the browser, web, or face-AI containers.
